# AI Agent Working Rules


Before completing any task:


Ask:


"Does this improve the NIRA experience?"


Prioritize:


1. User experience
2. Brand consistency
3. Code quality
4. Performance


Never prioritize:

- Speed over quality
- Decoration over meaning
- Complexity over usability
