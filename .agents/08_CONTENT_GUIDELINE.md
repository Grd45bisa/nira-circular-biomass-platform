# NIRA Content Guideline

# 1. Purpose

This document defines how written content for NIRA website should be
created.

Content must communicate: - Sustainability value - Human impact -
Transformation journey - Brand credibility

------------------------------------------------------------------------

# 2. Brand Writing Style

NIRA uses:

Formal Marketing Storytelling

Characteristics:

-   Professional
-   Warm
-   Clear
-   Inspirational
-   Human

The writing should feel like a premium sustainability brand.

------------------------------------------------------------------------

# 3. Writing Principles

## Be Meaningful

Every sentence must support: - Story - Value - Impact

## Be Simple

Avoid complicated terminology when simpler words can communicate better.

## Be Human

Focus on people behind the transformation.

------------------------------------------------------------------------

# 4. Avoid AI Generated Language

Avoid:

"In today's rapidly changing world..."

"Through innovative solutions..."

"We are committed to creating a better future..."

These phrases feel generic.

------------------------------------------------------------------------

# 5. Preferred Style

Use:

"From overlooked coconut resources, NIRA creates new possibilities for
nature and communities."

"Every coconut holds a hidden value waiting to be transformed."

------------------------------------------------------------------------

# 6. Content Structure

Most storytelling sections should follow:

Problem

↓

Opportunity

↓

Transformation

↓

Impact

↓

Future

------------------------------------------------------------------------

# 7. Headline Rules

Headlines should be:

-   Short
-   Emotional
-   Memorable

Examples:

Good: "Beyond The Shell"

Good: "From Waste To Worth"

Avoid:

Long descriptive headlines.

------------------------------------------------------------------------

# 8. Product Description Rules

Every product description must explain:

What is it?

How is it created?

Why does it matter?

------------------------------------------------------------------------

# 9. Impact Communication

Do not only show numbers.

Always connect numbers with human meaning.

Example:

Bad:

"5000 kg waste processed."

Better:

"5000 kg of coconut waste transformed into resources that support a
circular economy."

------------------------------------------------------------------------

# 10. CTA Writing

CTA should feel inviting.

Use:

"Explore NIRA"

"Discover The Transformation"

"Become Part of The Movement"

Avoid aggressive sales language.
