# NIRA SEO Performance Guide

# 1. SEO Goal

Make NIRA discoverable as a sustainability brand and circular economy
initiative.

------------------------------------------------------------------------

# 2. Metadata Rules

Every page must include:

-   Title
-   Description
-   Keywords
-   Open Graph image

------------------------------------------------------------------------

# 3. Page SEO Direction

Homepage:

Focus: NIRA sustainability transformation

Products:

Focus: Eco-friendly coconut products

Impact:

Focus: Circular economy and community empowerment

------------------------------------------------------------------------

# 4. Image Optimization

Rules:

-   Use Next Image
-   Compress images
-   Provide alt text
-   Avoid oversized assets

------------------------------------------------------------------------

# 5. Performance Target

Prioritize:

-   Fast first load
-   Smooth interaction
-   Low JavaScript usage

------------------------------------------------------------------------

# 6. Accessibility

Must include:

-   Semantic HTML
-   Proper heading hierarchy
-   Image alt text
-   Keyboard navigation

------------------------------------------------------------------------

# 7. Technical SEO

Prepare:

-   Sitemap
-   Robots.txt
-   Structured data
-   Canonical URLs

------------------------------------------------------------------------

# 8. Content SEO

Articles should focus on:

-   Circular economy
-   Coconut innovation
-   Sustainable products
-   Community empowerment
