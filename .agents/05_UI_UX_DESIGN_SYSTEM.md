# NIRA UI UX Design System

# 1. Design Philosophy

## Natural Premium Circular Experience

The interface should communicate:

-   Sustainability
-   Trust
-   Craftsmanship
-   Human impact
-   Modern simplicity

The design must feel like a premium sustainability brand, not a waste
management website.

------------------------------------------------------------------------

# 2. Visual Direction

Keywords:

-   Calm
-   Organic
-   Elegant
-   Minimal
-   Warm

Avoid:

-   Excessive gradients
-   Glassmorphism
-   Crowded layouts
-   Generic SaaS appearance

------------------------------------------------------------------------

# 3. Color System

## Primary Color

Deep Forest Green

HEX: #063522

Usage: - Primary button - Navigation - Brand emphasis - Dark sections

Meaning: Nature, growth, trust

------------------------------------------------------------------------

## Secondary Color

Warm Coconut Brown

HEX: #7a5645

Usage: - Accent - Illustration - Product highlight

Meaning: Craft, earth, human connection

------------------------------------------------------------------------

## Tertiary Color

Dark Wood Brown

HEX: #482510

Usage: - Footer - Strong contrast section - Material representation

------------------------------------------------------------------------

## Background Color

Warm Coconut Cream

HEX: #fcf9f0

Usage: - Main background - Content area

Avoid pure white backgrounds.

------------------------------------------------------------------------

## Text Color

Warm Black

HEX: #1c1c17

Usage: - Heading - Paragraph - Navigation

------------------------------------------------------------------------

# 4. Typography

## Heading Font

Style:

Elegant Serif

Recommended: - Playfair Display - Cormorant Garamond

Usage: - Hero title - Section title - Brand statement

------------------------------------------------------------------------

## Body Font

Style:

Modern Sans Serif

Recommended: - Inter - Manrope - Plus Jakarta Sans

Usage: - Paragraph - Navigation - Buttons

------------------------------------------------------------------------

# 5. Layout System

Container:

Maximum width: 1280px

Spacing philosophy:

Use generous whitespace.

The website should breathe.

------------------------------------------------------------------------

# 6. Button Design

## Primary Button

Background: #063522

Text: #fcf9f0

Style: - Rounded - Minimal - Premium

Example:

Explore NIRA

------------------------------------------------------------------------

## Secondary Button

Border: #063522

Background: Transparent

------------------------------------------------------------------------

# 7. Card Design

Product cards:

Must include:

-   Image
-   Product name
-   Short description
-   Sustainability value

Style:

-   Soft border
-   Natural shadow
-   Clean spacing

Avoid card overload.

------------------------------------------------------------------------

# 8. Image Direction

Use:

-   Real people
-   Natural environment
-   Coconut texture
-   Production process

Image feeling:

Authentic, warm, documentary style.

------------------------------------------------------------------------

# 9. Animation Rules

Animation should be:

-   Slow
-   Natural
-   Purposeful

Allowed: - Fade up - Smooth reveal - Parallax - Counter animation

Avoid: - Flashy transitions - Excessive movement

------------------------------------------------------------------------

# 10. Design Principle

Every visual element must support the story:

Nature → Transformation → Impact
