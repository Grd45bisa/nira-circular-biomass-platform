# NIRA Responsive Guideline

# 1. Responsive Philosophy

NIRA follows mobile-first responsive design.

The experience must remain consistent across devices.

Priority:

Mobile ↓ Tablet ↓ Desktop

------------------------------------------------------------------------

# 2. Device Categories

## Mobile Portrait

Width:

320px - 767px

Rules:

-   Single column layout
-   Compact spacing
-   Simplified navigation
-   Reduced decoration
-   Prioritize readability

------------------------------------------------------------------------

## Tablet Portrait

Width:

768px - 1024px

Important Rule:

Tablet portrait should follow mobile layout philosophy.

Use:

-   Single column
-   Larger spacing than mobile
-   Similar content order

Do not create a separate tablet design.

------------------------------------------------------------------------

## Tablet Landscape

Width:

1024px - 1366px

Use desktop layout approach.

Enable:

-   Multi-column sections
-   Larger imagery
-   Expanded storytelling

------------------------------------------------------------------------

## Desktop

Width:

1366px+

Full experience.

Use:

-   Maximum container width
-   Large visual storytelling
-   Complete navigation

------------------------------------------------------------------------

# 3. Breakpoint Strategy

Avoid designing for every device individually.

Use:

Mobile: \<768px

Tablet/Desktop: \>=1024px

Large Desktop: \>=1366px

------------------------------------------------------------------------

# 4. Navigation Rules

Mobile:

Use hamburger menu.

Desktop:

Use full navigation.

Navigation must remain simple.

------------------------------------------------------------------------

# 5. Section Rules

Mobile:

All sections become vertical.

Desktop:

Sections may use:

-   Two columns
-   Image-text split
-   Grid layouts

------------------------------------------------------------------------

# 6. Typography Scaling

Mobile:

Reduce heading size.

Maintain hierarchy.

Desktop:

Use large expressive headings.

------------------------------------------------------------------------

# 7. Image Rules

Mobile:

Images should not dominate content.

Desktop:

Hero images can become immersive.

Always optimize loading.

------------------------------------------------------------------------

# 8. Performance Rules

Mobile priority:

-   Fast loading
-   Minimal animation
-   Optimized images
-   Reduced JavaScript

------------------------------------------------------------------------

# Final Responsive Principle

Do not create different websites for different screens.

Create one consistent NIRA experience that adapts naturally.
